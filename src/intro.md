# 소개
Human-AI 협업을 위한 인터페이스 연구모입의 리서치 저장소입니다.

## 연구의 목적
인간과 LLM의 인지 시스템과 의사결정 방식을 연구하여 인간과 LLM의 상호 협업 가능한 구조와 방법론을 연구합니다.

본 리서치는 LLM, AI-Agent를 미션 중심의 수행 도구로 한정하지 않고, 인간과 LLM을 협업 파트너로 정의하고, 상호 협업의 대상으로 정의합니다.


## 주요 연구 과제 

* 사람 인지 시스템과 의사 결정 방식에 대한 조사 

* LLM 인지 시스템과 의사 결정 방삭에 대한 조사

* 사람 - LLM 커뮤니케이션 방식과 문제점에 대한 조사

## Usecase 연구 
* 기업 운영(경영)을 지원하는 인간 * LLM 워크스페이 모델
  
* 연구 리서치 * 투자 분석 등 디시즌을 우한 전문가 * LLM 협업 모델
  
* 퍼실리에이터로서의 LLM 에이전트 모델 (팀 멤버가 조율을 위한 에이전트 모델)

* 참여 규칙

  > 
  > 작성중인 글도 업로드 가능합니다. (예를 들어 초안, 작성 중에 있는 문서 가능)
